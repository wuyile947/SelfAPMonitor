# Self-AP-Monitor 使用说明

纯 Tkinter 桌面程序，无 Web 界面。仅限本人设备/本人热点使用；只采集网络元数据；
不解密 HTTPS、不做中间人、不伪造证书。管控动作通过 DNS 解析拦截、系统机制与
协议内连接终止报文（TCP RST / QUIC VN）实现，仅作用于本软件自己开启的热点。

## 1. 界面布局

```
┌────────────────────────────────────────────────────────────┐
│ 菜单栏: 文件 | 管控 | 工具 | 帮助                            │
├ 热点配置: SSID / WPA2密码 / 频段 / 最大连接数               │
│           [应用配置] [启动热点] [停止热点] [刷新]            │
│           热点状态行 + 识别引擎行                            │
├ 接入设备表格: MAC/IP/状态/首次上线/下行/上行/总流量/配额/标记 │
│              (右键 = 管控菜单)                              │
├ 设备详情 Tab页: 设备详情 | 实时会话 | DNS记录(库) | 告警/日志  │
├ 实时下行速率柱状图 (Canvas)                                 │
└ 状态栏: 抓包状态 | 包速率 | 活动流 | 识别引擎 | DB体积 | 法律提示│
```

## 2. 典型使用流程

### 第一步：配置并启动热点
1. 顶部填 SSID（1-32字符）、WPA2 密码（8-63位）、频段（Auto/2.4G/5G）、最大连接数
2. 点 **应用配置** → **启动热点**
3. 状态行显示 `On(已开启)` 即成功；Wi-Fi Direct 虚拟适配器出现后自动开始抓包

### 第二步：设备接入与识别
- 手机等设备连接热点后，10 秒内出现在中部表格
- **标记** 列：白名单 / 黑名单 / 陌生
- 首次出现陌生设备 → **弹窗告警**
- **识别引擎** 行显示当前后端：`nDPI x.x`（装了 libndpi.dll）或 `heuristic`（内置启发式）

### 第三步：查看流量观测数据
- **实时会话** 页：每条连接的对端/协议/识别类别/上下行/SNI/TLS版本/ECH标记/JA3
- **DNS记录(库)** 页：明文 DNS 查询域名；`加密=是` 表示 DoT(853) 或无明文DNS疑似加密DNS；
  `ECH=是` 表示出现 HTTPS(65) 记录或 ClientHello 带 ECH 扩展（仅做标记，不解析加密内容）
- **柱状图**：各设备 5 秒窗口下行速率。柱越高 = 当前网速越快；标签 = 设备内网 IP 末段（如 `137.62` 表示 `192.168.137.62`）；
  柱内颜色分段 = 该设备上线以来的流量构成（红=视频、蓝=文本、紫=下载、橙=游戏、绿=网页，右上角有图例）
- 设备详情页：单设备流量构成（视频/文本/下载/游戏等中文百分比 + 字节数）。
  分类依据是域名（SNI/DNS）与端口特征，只统计"属于哪类"的字节量，不采集任何内容

### 第四步：管控（右键菜单）
| 动作 | 实现机制 | 说明 |
|------|----------|------|
| 切断外网 / 恢复 | DNS 解析拦截（全部域名返回阻断应答）+ 连接层全杀（TCP RST/QUIC VN）+ ARP 回程黑洞（开关可选） | 秒级生效；针对 HTTPDNS 直连等绕过 DNS 的 App，由连接层与 ARP 层补杀 |
| 踢除设备 | 等同"切断外网"（DNS + 连接层全杀） | Windows 无"断开指定热点客户端"的公开 API，设备仍显示连着 WiFi 但完全不可达；要彻底断开请用下一项 |
| 彻底断网（重启热点） | 加入断网名单后关闭再开启热点，杀死全部既有连接（含已建立的 QUIC 1-RTT 连接） | 所有设备会短暂掉线（默认停机约 5 秒，可配置）；设备重连后立即被 DNS/RST/VN/ARP 多层拦截 |
| 弹出指定页面 | 类似 Captive Portal：设备访问明文 HTTP 站点时 301 跳转到指定 URL | 仅对 HTTP 有效；HTTPS 无证书不做跳转 |
| QoS限速 | New-NetQosPolicy（IPSrc/IPDst 双向） | 尽力而为，热点转发流量上不保证生效，见局限文档 |
| 流量配额 | 本地统计 + 超限自动断网 | 默认 90% 预警、100% 断网（可关） |
| 加入白/黑名单 | 配置持久化 | 黑名单设备接入时自动断网+弹窗 |
| 一键恢复全部（顶部按钮/右键菜单） | 清空断网名单、恢复 ARP 邻居表、移除本程序全部 SELFAPMON 系统规则 | 解除踢除/断网；QoS限速与配额需单独取消 |

### 第五步：全局管控规则（菜单"管控"）
- **DNS 过滤（执行层，默认开启）**：在热点网关 53 端口应答设备查询。设备断网、域名黑名单、
  短视频/广告屏蔽都依赖这一层；热点未开启时自动等待并重绑
- **连接阻断-主动 RST/VN（默认开启）**：对命中规则的连接注入协议内合法的 TCP RST 与
  QUIC Version Negotiation 报文终止连接建立，用于补上 App 内置 HTTPDNS 硬编码 IP 直连
  （不走系统 DNS）的绕过。仅作用于自家热点客户端，不伪造业务数据、不篡改通信内容，
  带有速率限制与同流去重保护
- **ARP 断流（默认开启）**：把断网设备写入主机邻居表静态黑洞（IP→不可达 MAC），
  使其收不到任何回程包，用于杀死三层拦截抓不到的**已建立 QUIC 连接**；恢复时自动还原。
  只改本机邻居表，不触碰设备、不做中间人
- **断网警告页（默认关闭）**：本机在网关 IP:80 提供"网络访问已受限"中文提示页，
  被断网设备的 DNS 应答指向网关，Android/iOS 明文联网检测会自动弹出提示
  （类似 Captive Portal）；HTTPS 站点连接失败，无证书不做中间人
- **屏蔽短视频App（内置，默认开启）**：内置抖音/快手/微视等域名清单（douyin.com/amemv.com/snssdk.com、kuaishou.com/gifshow.com/kwimgs.com、weishi.qq.com 等，
  含视频 CDN 域名与 HTTPDNS 引导域名，后缀+关键字匹配，自动覆盖子域）。
  设备查询这些域名时 DNS 层直接拦截；App 内置 HTTPDNS 直连时由 RST/VN 连接层按
  TLS SNI / HTTP Host / QUIC SNI 兜底。可随时开关；域名随版本失效时可在"域名黑名单管理"补充
- **网络净化（内置，默认开启）**：拦截穿山甲（字节）、优量汇（腾讯）、百度SSP、快手联盟、友盟、Google广告等广告SDK域名，
  命中明文 DNS 查询或 TLS/QUIC SNI → DNS 拦截 + 连接终止。
  对广告与内容**共用**的域名（pstatp.com/toutiao.com/bdstatic.com 等）不直接拦：
  登记 25 秒后按"连接数 + 流量大小"推断——多条短连接但总量 < 256KB（或单连接 60 秒仍 < 32KB）判定为广告上报并拦截该 IP，
  持续大流量则视为正常内容放行（1小时内不重复推断）。推断与拦截动作均记录在"告警与日志"页签
- **域名黑名单**：嗅探到明文 DNS 查询命中（如 `badsite.cn`、`*.evil.com`，精确规则同时覆盖子域）
  → DNS 层返回阻断应答；DoH/DoT/HTTPDNS 等明文 DNS 被绕过时由 TLS/QUIC SNI 连接层兜底
- **流量类型阻断**：开启后，识别为黑名单类别（Video/Game/Download/...）的连接登记到日志；
  注意实测 Windows 防火墙按远端 IP 的规则对热点转发流量不生效，实际拦截仍需依赖 DNS 过滤层
  （识别为 Unknown/DNS 的流不登记）

### 第六步：导出报表（菜单"文件"）
- 选择表（DNS查询 / 会话流 / 设备上下线 / 事件告警）+ 时间范围（天数）
- 导出 UTF-8 BOM CSV，Excel 可直接打开

## 3. 告警类型

| 告警 | 触发条件 | 默认 |
|------|----------|------|
| 陌生设备 | 非白名单 MAC 上线 | 弹窗 |
| 黑名单设备 | 黑名单 MAC 上线 | 弹窗 + 自动断网 |
| 流量突增 | 单设备下行 > 5MB/s 持续 3 个采样 | 弹窗 |
| 配额预警 | 已用流量 ≥ 配额 90% | 弹窗 |
| 配额超限 | 已用流量 ≥ 配额 | 弹窗 + 自动断网（可关）|

同类告警默认 300 秒冷却，避免刷屏（`config.json: alert_cooldown_sec`）。

## 4. 配置文件 `data/config.json`

常用字段（均可通过界面修改）：
```json
{
  "known_devices": ["aa:bb:cc:dd:ee:ff"],       // 白名单
  "blacklist_macs": [],                          // 黑名单
  "rate_spike_bps": 5242880,                     // 突增阈值 5MB/s
  "domain_blacklist": ["badsite.cn"],            // 域名黑名单
  "blocked_categories": ["Video"],               // 类型阻断
  "quota_auto_block": true,                      // 超配额自动断网
  "db_retention_days": 14,                       // 日志保留天数
  "db_max_mb": 200                               // 数据库体积上限(自动清理+VACUUM)
}
```

## 5. 数据与日志
- SQLite: `data/selfapmon.db`（devices / events / dns_log / flows 四张表）
- 日志轮转：启动时清理超过 `db_retention_days` 的记录；体积超 `db_max_mb` 时
  删除最旧明细并 VACUUM（事件日志保留）
- 所有数据仅存本地，不上传

## 6. 退出
关闭窗口时询问"是否清理本程序创建的防火墙规则"（推荐是）；
抓包线程、监控线程、写库线程一并安全停止。

## 7. 法律提示
- 本软件仅限在**本人所有或本人有权管理**的热点网络上使用
- 只采集元数据（五元组/包长/DNS查询名/TLS明文字段），**不具备也不尝试解密任何加密流量**
- 管控动作为对自有热点的访问控制：DNS 解析拦截、系统机制（防火墙/QoS/热点开关/邻居表）、
  协议内连接终止报文（TCP RST / QUIC VN）；不伪造业务数据、不篡改通信内容、不做中间人
- 未经授权监控/干扰他人设备可能违反《网络安全法》《个人信息保护法》及《刑法》285/286 条
