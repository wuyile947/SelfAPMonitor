# Windows 平台特有局限说明

本文档如实列出 Self-AP-Monitor 在 Windows 10/11 上由系统机制决定的局限。
这些局限源于 **Windows 公开 API 的能力边界**，不是本程序的设计取舍，
程序不会尝试用注入/伪造/中间人手段绕过它们。

---

## 1. 无法真正"踢除"指定热点客户端（最重要）

- Windows 的移动热点由 `NetworkOperatorTetheringManager` (WinRT) 管理，
  **没有公开 API 可以断开/取消认证某个已连接客户端**。
- 本程序"踢除/断网"的实际行为（多层叠加，设备仍然连着 WiFi，但无网络可达性）：
  1. DNS 解析拦截（该设备所有查询返回阻断应答/警告页地址）
  2. 协议内连接终止报文（任意 TCP 发 RST；QUIC 新连接发 Version Negotiation）
  3. ARP 邻居表静态黑洞（可选，默认开启）：主机到该设备的回程帧发往不可达地址，
     使其连回应包都收不到，用于杀死已建立的 QUIC 等长连接
- 唯一确定性的断开手段：
  1. 修改热点密码（所有设备全部掉线，重新连）
  2. 关闭再开启热点（同上，全部掉线）
- 对比：hostapd (Linux) 可以发 deauth 帧，Windows 公开接口不允许。

## 2. 单设备 QoS 限速 = 尽力而为

- `New-NetQosPolicy` 的限速（ThrottleRateMBps）作用在**本机协议栈的发送路径**上。
- 热点客户端的流量是**转发流量**（进 hotspot 网卡 → 路由 → 出外网网卡），
  客户端 SKU（Win10/11 家庭版/专业版）上 QoS 策略对转发路径**不保证生效**：
  - 家庭中文版常常直接拒收 QoS 策略（cmdlet 报错）
  - 专业版可能接受策略但对转发流量无实际效果
- 程序会如实返回下发结果；若限速无效，请依赖"配额+超限断网"这一组合
  （DNS 拦截 + RST/VN + ARP 黑洞是确定生效的控制手段）。
- 需要精确限速时，Windows 生态内可行的替代：组策略 QoS（域环境）、
  第三方 WFP 驱动级限速工具——均超出本程序"仅系统自带工具"的范围。

## 3. 防火墙规则对转发流量的生效情况

- **实测结论（本机多轮验证）**：按客户端 IP / 远端 IP 下发的
  `New-NetFirewallRule` 对热点 ICS 转发流量**不生效**——NAT 转发绕过主机
  ALE/传输层过滤点；`New-NetQosPolicy`、IPSec 策略同理。
- 因此本程序**不再用防火墙规则做设备级/域名级阻断**，设备断网与域名拦截改由
  DNS 过滤层 + 协议内连接终止（RST/VN）+ ARP 邻居表黑洞实现。
- 防火墙规则当前仅用于：放行断网警告页的入站 TCP 80（规则组 SelfAPMonitor，
  幂等下发，退出时清理）。
- 若未来 Windows 版本行为变化，以被控设备实测为准；程序把各动作结果写入事件日志。

## 4. 移动热点与 WinRT API 的怪癖

- **共享源依赖**：`GetInternetConnectionProfile()` 为空（无互联网）时无法创建
  TetheringManager —— 热点功能依赖"当前有可共享的联网网卡"。
- **热点开关后网卡延迟出现**：Wi-Fi Direct 虚拟适配器在开启后 1-3 秒才出现，
  程序在热点切换后延迟 2 秒再刷新并重启抓包；极端情况下需手动点"刷新"。
- **最大连接数**：`MaxClientCount` 的可设置性随系统版本浮动，
  程序尝试设置并在结果中注明是否成功（`max_client_set`）。
- **仅 Windows PowerShell 5.1**：WinRT 异步等待依赖
  `System.Runtime.WindowsRuntime`，PowerShell 7 (pwsh) 不支持，
  程序固定调用 `powershell.exe`。
- **频段/认证**：`Band` 属性在老版本 Win10 不存在（程序 try/catch 忽略）；
  热点默认 WPA2-PSK，24H2 起才有 WPA3 选项，本程序固定 WPA2 语义。
- **系统省电**：开启"按流量计费的连接"或系统休眠时热点可能自动关闭。

## 5. 抓包（Npcap/Scapy）的边界

- Npcap 是必需依赖；勾选"仅管理员可用"时必须以管理员运行本程序。
- 嗅探在热点虚拟适配器上进行，**只能看到经过该适配器的 IPv4 转发流量**
  （BPF 过滤 `ip`）；本机自身流量（如系统更新）不在采集范围。
- 高流量下的丢包：Scapy 用户态解析约数千 pkt/s 量级，超出后统计有轻微低估
  （速率/总量略偏小），不影响管控功能。
- IPv6 流量当前不采集（移动热点场景 IPv6 转发默认关闭）。

## 6. 元数据观测的天然盲区（不解密的代价）

这些盲区是"不做 HTTPS 解密/不做 MITM"的直接结果，属于设计约束而非缺陷：

| 场景 | 能看到的 | 看不到的 |
|------|----------|----------|
| TLS 1.2/1.3 普通 | SNI、ALPN、版本、JA3、包量 | URL、内容、证书外任何数据 |
| ECH (Encrypted Client Hello) | "使用了ECH"这一事实、外层SNI、包量 | 真实域名（仅记录为 ECH 标记）|
| DoT (853) / DoH | "在用加密DNS"这一事实 | 查询的域名 |
| QUIC (UDP 443) 新建连接 | 五元组、包量、端口特征、**Initial 中的 SNI** | 加密的应用数据 |
| QUIC (UDP 443) 已建立连接（1-RTT 短头部） | 五元组、包量、端口特征 | SNI 及一切握手信息（短头部无 version 字段） |
| VPN | 流量特征（端口/包型）与总带宽 | 隧道内任何信息 |

- QUIC Initial 使用 RFC 9001 规定的**公开算法**加密（任何人可解密，不涉及
  服务端密钥），本程序仅解密读取其中 ClientHello 的明文 SNI，用于规则匹配；
  不解析、也无法解析任何应用数据。
- **已建立的 QUIC 连接（1-RTT）协议内无法终止**：Version Negotiation 需要
  version 字段（短头部没有），伪造 stateless reset 需要服务端密钥（等同破解，
  不做）。本程序的对策是 ARP 邻居表黑洞（设备收不到回程，连接 idle 超时死亡）
  与"彻底断网"（重启热点杀死全部既有连接）。

- ECH 判定依据：DNS 查询 HTTPS(65) 记录、ClientHello 出现 ECH/ESNI 扩展类型
  （0xFE0D/0xFE03/0xFFCE 等）。ECH 全面普及后，域名黑名单的 SNI 兜底会失效，
  剩余手段为 DNS 应答 IP 阻断 + IP 级规则。
- nDPI 未集成时，识别靠 SNI 关键词 + 端口 + 明文载荷特征（BitTorrent/RTMP/STUN 等），
  对加密且无 SNI 的流量只能标 Unknown。

## 7. 其他系统级事项

- **防火墙弹窗**：首次抓包/建规则时 Windows 可能弹"是否允许"，需允许。
- **杀软误报**：Scapy 嗅探 + PowerShell 调用可能触发启发式告警，需自行加白。
- **数据面**：所有数据仅存本地 SQLite；卸载即删除目录。
- **多网卡/VPN 冲突**：宿主机开 VPN 时热点共享源可能被接管，导致热点断网，
  属 Windows ICS 行为，与程序无关。
- **语言区域**：程序内所有系统查询使用结构化输出（JSON/PowerShell 对象）
  或 Base64 编码命令，不受系统显示语言影响；`arp -a` 未采用。

## 8. 已知的功能边界汇总表

| 需求 | 实现程度 |
|------|----------|
| 热点 SSID/密码/频段/最大连接数 配置 | ✅ 完整（MaxClientCount 视版本）|
| 热点启停/状态 | ✅ 完整（WinRT）|
| 客户端列表/在线状态 | ✅ 完整（ARP+ping 探测，5s 周期）|
| 踢除指定设备 | ⚠️ 多层阻断（DNS + RST/VN + ARP 黑洞），无法真正 deauth；需确定性断开用"彻底断网"重启热点 |
| 单设备 QoS 限速 | ⚠️ 尽力而为（转发流量可能不生效）|
| 切断外网 | ✅ DNS 拦截 + RST/VN + ARP 黑洞，多层叠加 |
| 流量配额 | ✅ 完整（超限断网确定生效）|
| DNS 域名记录/ESNI-ECH 标记 | ✅ 明文 DNS 完整；加密 DNS 仅标记 |
| TLS 握手元信息 | ✅ SNI/ALPN/JA3/版本/ECH（ECH 下无真实 SNI）|
| QUIC 元信息 | ✅ 新连接 Initial 的 SNI（公开算法解密）；已建立 1-RTT 连接不可见、协议内不可终止 |
| 按域名/类型阻断 | ✅ DNS 层拦截 + SNI 命中发 RST/VN；防火墙按 IP 阻断对转发流量实测无效 |
| 日志轮转/CSV 导出 | ✅ 完整 |
| 告警（陌生/突增/配额）| ✅ 完整（带冷却）|
