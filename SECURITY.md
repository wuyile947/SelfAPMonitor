# Security

If you find a security issue, vulnerability, or a case of misuse/abuse related to SelfAPMonitor, please report it to the project maintainer at:

Email: 13324019139@163.com

Preferred reporting workflow
1. Send an email to the address above with:
   - A short summary of the issue
   - Steps to reproduce (or a minimal repro)
   - Impact and any suggested mitigation
   - Your contact information if you want a follow-up
2. If the issue is an active abuse or public safety concern, include timestamps and any evidence (logs, screenshots).

If you prefer, you may also open a GitHub Issue (use the "security" or "bug" labels). For sensitive reports containing exploit details, prefer email to avoid public disclosure.

Note on responsible disclosure
- Please avoid public disclosure of unreleased or exploitable details until a fix or mitigation is available.
- The project maintainer will respond as promptly as possible but may not be able to provide a detailed timeline.
