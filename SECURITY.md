# Security / 安全报告

If you find a security issue, vulnerability, or a case of misuse/abuse related to SelfAPMonitor, please report it to the project maintainer using the contact channels below.

- Sensitive / private reports (vulnerabilities, exploit details, abuse, legal/privacy issues):
  - Email: 13324019139@163.com
  - Please send: short summary, steps to reproduce or minimal repro, impact, evidence (logs/screenshots), and your contact info if you want follow-up.
  - For sensitive technical details, prefer email to avoid public disclosure.

- General suggestions, feature requests, non-sensitive bug reports:
  - Preferred: open a GitHub Issue in this repository (https://github.com/wuyile947/SelfAPMonitor/issues)
  - Or email: 13372832317@163.com

Preferred reporting workflow
1. Send an email to the appropriate address above or open a GitHub Issue for general items.
2. If the issue is an active abuse or public safety concern, include timestamps and any evidence (logs, screenshots).

Note on responsible disclosure / 负责任披露
- Please avoid public disclosure of unreleased or exploitable details until a fix or mitigation is available.
- The project maintainer will respond as promptly as possible but may not be able to provide a detailed timeline.

如果你发现安全问题或滥用情况，优先通过上面的邮件地址私下报告；普通建议和 issue 请使用 GitHub Issues 或发送到第二个邮箱。
